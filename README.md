# Head or Tails

This is a small Python game I made to practice using functions and get more comfortable with them.

## How it works

You fight an NPC by guessing whether a coin will land on Head or Tail.

* You choose Head or Tail
* The coin randomly chooses the actual result
* The NPC also makes a random guess
* If you guess correctly, you deal damage
* If the NPC guesses correctly, it deals damage to you
* Both start with 100 health
* Damage is randomly chosen between 10 and 50
* The fight ends when either the player or NPC reaches 0 health
